# Рубрика: SECURITY — безопасность

Публикуй 2-3 раза в неделю, а также при обнаружении подозрительного
источника. Не привязывай к конкретному запуску проверки.

## Шаблон

🛡 Важное правило безопасности

Не отправляйте никому:

• код входа в Telegram;
• пароль;
• токен бота;
• seed-фразу;
• приватный ключ;
• резервные коды;
• QR-код доступа.

Перед установкой клиента проверьте:

1. источник загрузки;
2. официальную страницу проекта;
3. разрешения приложения;
4. дату обновления;
5. репутацию разработчика.

VPN помогает изменить маршрут трафика, но сам по себе
не гарантирует абсолютную анонимность.

Если источник требует код Telegram или пароль — не используйте его.
