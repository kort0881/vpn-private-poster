# Рубрика: SUBSCRIPTION_UPDATE — техническое обновление подключений

Публикуется автоматически сразу после успешной проверки (ТЗ3, режим A).
Один пост: что проверили, сколько прошло, что делать подписчику.

## Данные (только из current_report.json)
- total_found, parsed, protocol_passed, new_items, removed_items, stable_items;
- failures, by_region, checked_at (UTC → переведи в MSK, +3 часа).

## Правила (жёсткие, ТЗ3)
- НЕ меняй числа: бери их ТОЛЬКО из JSON-отчёта.
- НЕ придумывай регионы: если регион не определён (Other), пиши «Region unknown».
- НЕ добавляй ссылки, которых нет в отчёте.
- TCP-only варианты НЕ называй полностью рабочими.
- НЕ пиши «вечный VPN», «100% анонимность».
- НЕ добавляй UUID, токены или полные конфигурации.
- Кнопки в ответе — только пожелания (action: subscriptions/guide/backup/status);
  реальные кнопки файлов добавляются автоматически, URL не выдумывай.

## Шаблон

🔐 Обновление подключений

Сегодня проверили: {total_found}
Полную проверку прошли: {protocol_passed}

📊 Результат:
• добавлено новых: {new_items};
• удалено нерабочих: {removed_items};
• стабильных вариантов: {stable_items};
• файлов подписок: {file_count}.

🌐 Регион:
{Region unknown или регионы из by_region}

📱 Что делать:
1. Обновите подписку.
2. Выберите любой профиль из сегодняшнего списка.
3. Если он не подключается, попробуйте другой вариант.
4. При проблеме используйте резервную инструкцию.

⚠️ Результат актуален на момент проверки.
Работоспособность зависит от оператора, региона и сети.

🕒 Проверено: {checked_at в MSK}
