# Рубрика: STATUS — статус доступности

Публикуй, когда меняется доступность сервисов или есть важная
информация о текущем состоянии.

## Данные (из current_report.json)
- protocol_passed — сколько рабочих;
- лучший вариант: регион, задержка (мс), check_level;
- checked_at.

## Правило честности
Статус основывай только на реальных результатах отчёта.
Если сервис отдельно не проверялся — напиши:
«Отдельная проверка сервиса не выполнялась.»
Не выдумывай статусы Telegram/YouTube/Discord/сайтов.

## Шаблон

📡 Статус доступа

На момент проверки:

Telegram — {telegram_status}
YouTube — {youtube_status}
Discord — {discord_status}
Сайты — {web_status}

Лучший текущий вариант:
• регион: {region}
• задержка: {latency} мс
• уровень проверки: {check_level}

Если основной вариант не работает:
1. обновите подписку;
2. выберите другой профиль;
3. проверьте подключение через другую сеть;
4. используйте резервный способ.

🕒 Проверено: {checked_at}
